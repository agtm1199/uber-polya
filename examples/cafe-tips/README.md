# Cafe Tips Example

A cafe owner tests whether background music genre affects tipping behavior: jazz vs pop, 25 days each.

## Problem

- **Jazz days**: 25 days, mean tip 18.2% (std 2.2)
- **Pop days**: 25 days, mean tip 15.9% (std 3.0)
- **Question**: Does music genre significantly affect tips?

## Files

| File | Purpose |
|------|---------|
| `cafe_solver.py` | Full uber-polya pipeline: model, solve, verify, interpret, visualize |
| `solution.json` | Machine-readable solution (generated by solver) |
| `cafe_tips_analysis.png` | Group comparison with distributions (generated) |
| `cafe_power_curve.png` | Statistical power vs sample size (generated) |

## Quick Run

```bash
pip install scipy numpy matplotlib
python cafe_solver.py        # runs all 4 Polya phases + generates charts
```

## Expected Output

- **t-statistic**: 3.09, **p-value**: 0.0035 (significant at alpha=0.05 and 0.01)
- **Cohen's d**: 0.87 (large effect)
- **Mean difference**: $2.30 higher tips on jazz days
- **95% CI**: [$0.80, $3.80]
- **P(jazz > pop)**: 99.9% (Bayesian)
- **Power**: 85.6% (well-powered)
- **All 3 verification methods agree**: Mann-Whitney, permutation test, bootstrap CI

## Key Concepts

- **Full Polya cycle**: Model (Phase 1-2) -> Solve (Phase 3) -> Interpret (Phase 4) in one script
- **Assumption checking**: Shapiro-Wilk normality + Levene's equal variance before parametric test
- **Triple verification**: Parametric (t-test), nonparametric (Mann-Whitney), and resampling (permutation + bootstrap) all agree
- **Effect size over p-value**: Cohen's d = 0.87 tells the practical story; p-value alone does not
- **Power analysis**: n=25 gives 85.6% power; n=22 would suffice for 80%
- **Bayesian complement**: Posterior probability gives an intuitive business answer

## Domain

Statistical Inference -- Hypothesis Testing, Effect Sizes, Bayesian Estimation, Power Analysis, Bootstrap Resampling.
