# Call Center Queuing Analysis

A call center queuing system: how many agents are needed to meet service-level targets?

## Problem

- **Arrivals**: Poisson process at lambda = 20 calls/hour
- **Service**: Exponential service time, mu = 6 calls/hour/agent
- **Current staff**: 4 agents (M/M/4 queue)
- **Questions**:
  1. What is the average wait time with 4 agents?
  2. How many agents are needed for < 2 minute average wait?
  3. What happens if call volume increases 50%?

## Files

| File | Purpose |
|------|---------|
| `queuing_solver.py` | Solver: M/M/c analytical + SimPy DES verification |
| `solution.json` | Machine-readable solution (generated by solver) |

## Expected Output

- **M/M/c analytical results**: P0, Erlang-C P(wait), Lq, Wq, L, W for c=4 agents
- **Little's Law check**: L = lambda * W verified within tolerance
- **Staffing analysis**: Wq for c=1..10, minimum c for < 2 min average wait
- **Growth scenario**: Repeat analysis with lambda' = 30 calls/hour (50% increase)
- **SimPy DES verification**: 200,000-customer simulation (10,000 warm-up discarded), simulated Wq matches analytical Wq within 10%
- **Staffing recommendation**: Minimum agents for current and growth scenarios

## Key Concepts

- **M/M/1 and M/M/c**: Markovian single-server and multi-server queues with Poisson arrivals and exponential service
- **Erlang-C formula**: Probability an arriving customer must wait in an M/M/c queue
- **Utilization (rho)**: Server utilization rho = lambda / (c * mu); must be < 1 for stability
- **Little's Law**: L = lambda * W (fundamental relationship between queue length and wait time)
- **Warm-up period**: Discard initial transient observations in simulation before collecting statistics
- **Discrete-Event Simulation (DES)**: SimPy-based simulation to cross-validate analytical results
