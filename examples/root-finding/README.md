# Root Finding & Interpolation

An engineer needs to find the operating temperature where a material's thermal expansion coefficient equals a target value.

## Problem

Given 8 measured data points of temperature (0--700 degC) vs. thermal expansion coefficient alpha(T), which increases nonlinearly from ~9 to ~16 x10^-6 /degC:

1. **Root finding**: Find the temperature where alpha(T) = 12.0 x10^-6 /degC by solving g(T) = spline(T) - target = 0
2. **Method comparison**: Compare 4 root-finding methods -- bisection, Newton (finite-difference), secant, and Brent
3. **Interpolation comparison**: Fit the data using linear, cubic spline, and Lagrange interpolation
4. **Numerical integration**: Integrate alpha(T) over [100, 500] degC using trapezoidal, Simpson, and Gaussian quadrature

- **Integration**: All 3 quadrature methods agree within 1%
- **8 verification checks**: All pass

## Key Concepts

- **Bisection**: Guaranteed convergence (linear rate), requires bracket
- **Newton's method**: Quadratic convergence near root, needs derivative (approximated via finite difference)
- **Secant method**: Superlinear convergence (~1.618), no derivative needed
- **Brent's method**: Combines bisection reliability with superlinear speed -- the gold standard
- **Cubic spline**: C2-continuous interpolation that passes exactly through data points
- **Gaussian quadrature**: Exact for polynomials up to degree 2n-1 with n points
