# A/B Test Example

A website checkout flow A/B test: does the new checkout design increase conversions?

## Problem

- **Control (A)**: 1,500 visitors, 60 conversions (4.00%)
- **Treatment (B)**: 1,500 visitors, 85 conversions (5.67%)
- **Question**: Is the new checkout significantly better?

## Files

| File | Purpose |
|------|---------|
| `ab_solver.py` | Solver: z-test + Bayesian + bootstrap + power analysis |
| `ab_viz.py` | Visualizations: conversion comparison + power curve |
| `solution.json` | Machine-readable solution (generated by solver) |

## Quick Run

```bash
pip install scipy numpy statsmodels matplotlib
python ab_solver.py          # solve + verify
python ab_viz.py             # generate charts
```

## Expected Output

- **Z-statistic**: ~2.36, **p-value**: ~0.018 (significant at alpha=0.05)
- **Cohen's h**: ~0.130 (small effect)
- **P(B > A)**: ~98.9% (Bayesian)
- **Power**: ~65% (underpowered for this effect size)
- **Recommendation**: "CAUTIOUS" -- significant but small effect

## Key Concepts

- **Three-way verification**: z-test, Fisher's exact, and chi-squared all agree
- **Bayesian complement**: P(B > A) gives intuitive "probability B is better" answer
- **Power analysis**: Only 65% power -- we might miss effects this small
- **Sensitivity**: Power curve shows how detection improves with sample size

## Domain

Statistical Inference -- Hypothesis Testing, Bayesian Estimation, Power Analysis.
