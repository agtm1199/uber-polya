# Bin Packing -- Container Loading

A shipping company needs to pack 25 items of various weights into containers, minimizing the number of containers used. Compares a heuristic approach with the exact ILP optimal.

## Problem

- **Items**: 25 packages with weights ranging from 5 to 45 kg (generated from seed=42)
- **Container capacity**: 100 kg each
- **Objective**: Minimize the number of containers used
- **Approaches**: First Fit Decreasing (heuristic) vs. ILP (exact optimal)

## Files

| File | Purpose |
|------|---------|
| `bin_solver.py` | Solver: FFD heuristic + ILP optimal + utilization analysis |
| `solution.json` | Machine-readable solution (generated by solver) |

- **ILP optimal**: 7 bins, average utilization ~93%
- **Lower bound**: ceil(648 / 100) = 7 bins
- **Utilization analysis**: Both FFD and ILP achieve the lower bound; FFD minimum bin utilization is 59% while ILP achieves at least 83%
- **All 8 verification checks pass**

## Key Concepts

- **Bin packing**: Classic NP-hard combinatorial optimization problem
- **First Fit Decreasing (FFD)**: Sort items largest-first, place each in the first bin that fits
- **NP-hardness**: No known polynomial-time exact algorithm; heuristics provide fast approximations
- **Approximation ratio**: FFD uses at most ceil(11/9 * OPT + 6/9) bins
- **ILP relaxation**: Integer Linear Programming finds the provably optimal solution
